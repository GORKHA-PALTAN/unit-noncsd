EXPO GO (optional)
==================
The normal QR codes on the dashboard page "Share & QR codes" open the store in the phone's
browser and need nothing extra. Use this folder only if you want the store to open inside the
Expo Go app.

One-time setup
1. Install Node.js (LTS) from https://nodejs.org on the computer that runs the store.
2. Install "Expo Go" on the phone (Play Store / App Store).

Every time
1. Start the store as usual (start-windows.bat).
2. Double-click expo-app\start-expo-windows.bat   (Mac: bash expo-app/start-expo-mac.sh)
   The first run takes a few minutes. Allow it through the firewall if asked.
3. Open the dashboard page "Share & QR codes" and scan an "Expo Go" code:
   - Android: open Expo Go > "Scan QR code".
   - iPhone: scan with the Camera app; it opens in Expo Go.
The phone must be on the same Wi-Fi as the computer.
